Contains information from the United Nations Statistics Division, M49 (https://unstats.un.org/unsd/methodology/m49/overview/). Licence: unclear (none stated by the source). Columns: ISO3166-1-Alpha-3, M49, the official_name_* columns, and the Global, Region, Sub-region and Intermediate Region columns, Least Developed Countries (LDC), Land Locked Developing Countries (LLDC) and Small Island Developing States (SIDS).

Contains information from Statoids (https://statoids.com/wab.html). Licence: unclear (none stated by the source, which carries a copyright notice). Columns: ISO3166-1-Alpha-2, ISO3166-1-numeric, ITU, FIPS, IOC, FIFA (first pass), DS, WMO, GAUL, MARC, Dial, is_independent.

Contains information from the ISO 4217 currency code list published by SIX Group, the ISO 4217 maintenance agency (https://www.six-group.com/dam/download/financial-information/data-center/iso-currrency/lists/list-one.xml). Licence: unclear (none stated by the source). Columns: ISO4217-currency_country_name, ISO4217-currency_name, ISO4217-currency_alphabetic_code, ISO4217-currency_numeric_code, ISO4217-currency_minor_unit.

Contains information from the FIFA member associations list (https://inside.fifa.com/associations). Licence: unclear (none stated by the source). Column: FIFA.

The ISO 3166-1 and ISO 4217 codes are published by ISO (https://committee.iso.org/iso-4217-currency-codes.html). Licence: unclear. ISO allows free-of-charge use of its country, currency and language codes and says that any use, including reproduction, requires its written permission.

Changes made to the source data: the scripts in scripts/ download each source and join the tables into one file by ISO alpha-3 code, alpha-2 code or country name. Columns are renamed and reordered, duplicate rows are dropped, and rows are sorted by official_name_en. UNTERM rows that are not complete in all six languages are skipped. SIX entries marked as funds are skipped, and when a country has several currencies the values are joined with commas. For CLDR, where a name has a "-alt-short" form, that shorter name is used; "-alt-variant" names, numeric region codes and the codes ZZ, EZ and EU are ignored. FIFA values that are not on FIFA's list are replaced by the country's ISO alpha-3 code when that code is on the list. For Wikidata, the entity ID is turned into a URL, and a few duplicate or retired items are removed. No GeoNames, CLDR, SEC or Wikidata value is otherwise edited.
